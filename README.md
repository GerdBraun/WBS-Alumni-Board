# WBS Alumni Board - Frontend

## Purpose

WBS Alumni Board is a hub for alumni of WBS Coding School to connect, share information, and collaborate. The platform enables users to post and discover projects, tech jobs, and vacancies, as well as engage in discussions through comments and Q&A.

## Features

- **User Registration & Login:** Secure authentication for alumni.
- **Project Board:** Post and browse collaborative projects.
- **Job Listings:** Share and find tech job opportunities.
- **Comments & Q&A:** Interact with posts, ask questions, and provide answers.
- **User Profiles:** View and manage personal information.

## Technologies Used

- **React** (Frontend UI)
- **Redux** (State management)
- **React Router** (Navigation)
- **Axios** (API requests)
- **Material-UI** (Styling and components)
- **Tailwind CSS** (Utility-first CSS framework)
- **DaisyUI** (Tailwind CSS component library)


You can try the live demo here: [https://wbs-alumni-board.onrender.com/](https://wbs-alumni-board.onrender.com/)

To get started:

1. **Register an account:**
    - Click "Register" on the homepage.
    - Fill in your details and submit.

2. **Log in:**
    - Use your credentials to log in.
    - Start exploring posts, jobs, and projects!

For backend details, refer to the README in the `backend` directory.
